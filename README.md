# 🛡️ Portfólio de QA: Análise e Documentação (Foco em Segurança e Qualidade)

> Este projeto demonstra como aplico meu background acadêmico em **Segurança da Informação** dentro de processos de **Qualidade de Software (QA)**, com foco em análise, prevenção de riscos e validação de fluxos críticos.

## 🎯 Objetivo do Repositório
Demonstrar na prática o conceito de **Shift-Left Testing** (trazer a segurança para o início do desenvolvimento). Aqui, apresento artefatos de documentação que visam não apenas garantir que o software funcione (testes funcionais), mas que ele seja robusto contra falhas e abusos (testes de segurança/abuso).

## 📂 O que você vai encontrar aqui
Este repositório foca na **estratégia e análise**, simulando a documentação de um QA analítico:

* **[`/docs/plano-de-teste.md`](./docs/plano-de-teste.md)**: Planejamento estratégico do que será validado.
* **[`/docs/cenarios-gherkin.feature`](./docs/cenarios-gherkin.feature)**: Escrita de requisitos em BDD, incluindo cenários de "Caminho Infeliz" (ex: SQL Injection e Brute Force).
* **[`/docs/matriz-de-risco.md`](./docs/matriz-de-risco.md)**: Priorização de testes baseada em impacto e probabilidade (Mentalidade de Risco).
